## 🎯 Project Overview

## 🛠️ Testing Approach

### 🔍 Requirement Analysis
- Understand website flow and course page structure  

### 🧪 Test Case Design
- Created test cases with inputs and expected outputs  

### ▶️ Test Execution
- Performed manual testing by simulating real user actions  

### 🐞 Bug Identification
- Detected issues in navigation, UI, and performance  

### 🔁 Retesting & Regression
- Verified bug fixes and checked system stability
